# Grunt v0.1 Product Vision

## Problem

Human workers spend 60–80% of their time on repetitive, low-autonomy tasks — "grunt work" — that follow predictable patterns but require manual effort. This is a massive tax on human productivity and creativity.

## Solution

Grunt is a daily-generational system that:
1. **Identifies** grunt work patterns through continuous internet research
2. **Builds** agent persona templates that automate those patterns
3. **Scores** each template scientifically against real-world effectiveness
4. **Self-iterates** — each generation improves on the last, compounding toward perfection

## Target User

Any knowledge worker, developer, or team spending time on:
- Repetitive code tasks (boilerplate, migrations, config updates)
- Information aggregation and summarization
- Routine communication and scheduling
- Data transformation and reporting
- Standard operating procedures

## Success Metric (v0.1)

> **Grunt Units Eliminated (GUE)**: The number of human-hours of grunt work automated per 30-day cycle.

**v0.1 target**: 100 GUE per month (10 templates × 10 hours saved each)
